A lightweight C# console utility designed to generate professional file catalogs. It scans a specified path and exports an alphabetically sorted list of all files directly into a styled Excel (.xlsx) spreadsheet.

## Features
* **Automated Scanning:** Extracts all file names from a target directory, with a built-in toggle to optionally remove file extensions.
* **Alphabetical Sorting:** Automatically orders files to create a clean, easy-to-read catalog.
* **Polished Excel Export:** Powered by ClosedXML, the output features custom LightBlue/AliceBlue row styling, thick black borders, and hidden gridlines.
* **Smart Formatting:** Automatically adjusts column widths to fit your file names, left-aligns index numbers for a clean margin, and center-aligns file text.

## Installation & Setup
1. Clone the repository.
2. Open the project in Visual Studio.
3. Ensure the ClosedXML package is installed via the NuGet Package Manager.
